## Bug 2 observation (primary determination)

```bash
oc -n logicmonitor logs -f deploy/lm-monitoring-v032-test-collectorset-controller \
  --tail=200
```

Decision criteria:

- **FIXED**: log line resembling "creating collector group" or "collector
  group created" or successful POST result. Collector pods proceed to
  Ready state. LM portal `Kubernetes Cluster: aro-v032-test` reappears
  with the new collectors registered (verify via
  `mcp__logicmonitor__get_collector_groups(name_filter="aro-v032-test")`).
- **NOT FIXED**: repeated "Collector group does not exist. Retrying in
  1 minute..." with no successful creation. CSC pod alive but collector
  pods never reach Ready. LM portal group never reappears.

Capture the first 10 minutes of CSC logs to
`/tmp/v0.3.3-csc-logs.txt`.

## Bug 1 smoke test (post-install reconciliation loop)

```bash
oc -n logicmonitor get secrets -l owner=helm,name=lm-monitoring-v032-test \
  -o jsonpath='{range .items[*]}{.metadata.name}{"\n"}{end}' | wc -l
# Expected: a stable small number (e.g. 1-3), not climbing.
# Re-check after 5 minutes; the count must NOT have increased significantly.
```

Also check the operator log for reconcile noise:

```bash
oc -n logicmonitor logs deploy/logicmonitor-openshift-operator-controller-manager \
  --tail=100 | grep -Ei "reconcile|upgrade" | wc -l
# Expected: quiet (single-digit lines, no infinite reconcile loop).
```

## Bug 5 smoke test (argus Deployment companyDomain default)

```bash
oc -n logicmonitor get deploy lm-monitoring-v032-test-argus 2>&1
oc -n logicmonitor logs deploy/lm-monitoring-v032-test-argus --tail=30 | \
  grep -Ei "lookup|fatal|dial tcp.*\.\.|companyDomain"
# Expected: no "lookup ... on .. no such host" errors with the trailing-dot
# URL signature. Argus discovery agent should resolve LM API normally.
```

Verify the COMPANY_DOMAIN env var is set:

```bash
oc -n logicmonitor get deploy lm-monitoring-v032-test-argus -o jsonpath=\
  '{.spec.template.spec.containers[0].env[?(@.name=="COMPANY_DOMAIN")].value}'
# Expected: "logicmonitor.com" (or the value provided in global.companyDomain)
```

## Bug 4 smoke test (lm-logs with userDefinedSecret)

Toggle `lm-logs.enabled: true` in the CR:

```bash
oc -n logicmonitor patch lmcontainer lm-monitoring-v032-test \
  --type=merge --patch '{"spec":{"lm-logs":{"enabled":true}}}'
```

Verify:

```bash
oc -n logicmonitor get ds lm-monitoring-v032-test-lm-logs 2>&1
# Expected: DaemonSet exists; DESIRED == CURRENT == READY (matches node count).
oc -n logicmonitor logs ds/lm-monitoring-v032-test-lm-logs --tail=30 | head -20
# Expected: no "userDefinedSecret=... not found in namespace" failure.
```
